title: "Evaluating Python Asyncio for an Application Server Herd"

abstract: "Python's asyncio framework is a networking library intended for asynchronous communication across multiple interconnected servers. This paper investigates its merit as a potential candidate for making a platform of interconnected servers that is like Wikimedia but updates to articles happen far more often, access is required via multiple protocols and clients are more mobile. In comparison to traditional centralized application-server architectures, this will be implemented using an application server herd. An application server herd sends updates directly between servers, thus removing the need for a central server/database. To investigate the suitability of asyncio for this environment, I implemented a prototype consisting of five interconnected servers. The prototype accepts client location updates, propagates them throughout the server herd using an asynchronous flooding algorithm, and retrieves nearby location information through the Google Places API. Results from the protoype indicate that asyncio significantly simplifies the development of concurrent network applications using asynchronous I/O. However, Python's dynamic type system, global interpreter lock, and cooperative scheduling model introduce limitations compared to statically typed, multithreaded Java-based solutions. Despite these limitations, asyncio is well suited for I/O-bound distributed services such as the application server herd studied here. This leads me to conclude that asyncio is indeed a practical framework for this scenario."
